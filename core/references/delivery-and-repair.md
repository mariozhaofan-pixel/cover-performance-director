# 交付、修订与检查

## 交付顺序

内部完成初稿、适用检查及可以直接确定的修正，然后一次交付完整受影响提示词。不要先发已知有问题的全文再重发。用户只要正文则内部自检，不附工具过程、JSON或反复验收报告。格式和工程范围由调用入口负责。

分别记录三种状态：

1. **正文**：符合当前要求，或仍缺必要内容。
2. **时间证据**：无精确要求／参考时序已核对／最终音轨时序已核对／候选待核准。
3. **生成条件**：当前步骤实际需要的素材及能力已具备，或列具体缺口；实际生成是否发生单独说明。

通用草稿可以完成文字方案，严格逐句时码未满足时仍是待调整。不能靠免责声明判通过，也不因平台未选就阻止通用正文。可靠证据已有就不再次索要确认。

## 一次适用检查

| 项目 | 实际检查 |
| --- | --- |
| 歌词 | 本次范围、原文、句序、重复出现次序、每段歌词块与分镜唱词一致；无旧歌残留 |
| 音轨 | 歌曲参考、角色声线、最终音轨职责明确；音轨处理与清唱/伴奏/弹唱相容 |
| 上传额度 | 所有选中音频时长之和符合入口上限，至少给声线预留4秒；备用轨与旧参考未混入上传集合；没有为视频收尾给歌曲参考补长 |
| 格式 | 默认导演五栏，独立与内置一致；用户其他格式要求优先 |
| 时间 | 原音频范围、首词、尾音、文件尾、片头片尾与三层时码一致；不把候选当核准 |
| 分段 | 所选全范围无漏歌/重唱；每段可独立执行；长音和跨段状态连续 |
| 表演 | 发音优先，视线顺序正确，变化有进入停留退出；不遮嘴、不超画框、不占气口 |
| 画面 | 身份/造型/光色稳定，摄影符合当前要求与动作可见性，素材只控制指定维度 |
| 修订 | 只修改请求及其必要依赖，歌词/声音/总则/分镜/约束同步，未受影响项保留 |
| 交付 | 无空栏、同上、虚构引用或操作状态；格式服从适配层，本轮范围完整 |

只能核对已提供内容。能直接确定的内部矛盾立即修正；真正缺资料或需取舍集中说明，不继续依赖它的步骤。修订后仅复核受影响项及其全文一致性，不因文件多或曲目长自动扩展审核。

## 有界修改

**微修**：只改某句眼神幅度、一个手势或措辞且不改变时间/范围/构图证据；冻结其他歌词、重复句定位、时码、声音、镜头和状态。只读目标段与必要上下文，不重听整首、不重选风格或重建资产。

**局部修订**：改音频范围、气口、起唱点、声音组织、镜头可见范围或跨段接力；更新真实受影响依赖。例如换声线但还没取得最终歌声，原最终音轨的精确口型时码不能直接沿用；仅删除画面吉他不代表删除伴奏。

**重编**：换歌、换最终音轨或用户明确从头设计；清除旧歌曲专属动作、片头、尾段和情绪峰，只迁移用户仍保留的身份、场景和要求。同曲删某次重复句按出现位置操作，保留的动作意图重新安放，不误删全部同词句。

用户要求完整稿就交更新后的完整受影响段，不能只发补丁；未请求范围不扩写。改词同步歌词块和分镜；改声音模式清除相反禁令；改动作涉及景别只作必要构图调整。

## 使用交接与成片问题

按实际需要交代素材名称/职责、音频版本和范围、画幅、目标模型及生成段顺序。原生引用语法、音频输入、重唱、最终音轨保留和口型能力以当前官方资料或真实工具结果为准；功能名不等于能力保证。不擅自换模型、裁歌、变速或改声去迁就限制。

反馈“跑调/对不上”但无成片或导出音轨时，只给可能原因及所需验证材料。取得证据后区分音高偏移、整体合法移调、人声伴奏调性不一、节奏错位、音画偏移和嘴部发音错位，按定位修复，不一律增加负面提示词。

当前技能负责真实音频预处理、提示词与表演编排。分离成功只证明获得参考人声和备用伴奏；用户要求实际新音色重唱或视频时，沿已有授权衔接可用工作流。缺工具就保留可执行文字、已完成音频及明确缺口，不报告已制作新歌声、已绑定素材或已生成成片。
