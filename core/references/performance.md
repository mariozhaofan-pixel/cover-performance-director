# 演唱表演

## 从乐句建立连续过程

先依实际音乐、确认歌词与用户方向确定进入、发展、峰值和回落，再选关键乐句。高音/高潮有声音依据或用户指定才作为事实；不能只凭歌词“爱、痛、飞”推断高音或机械配动作。

内部按“歌词及出现次序 → 声音/情绪触发 → 起始姿态与视线 → 主变化 → 停留 → 收束 → 下一句状态”组织。普通乐句可以延续，不强迫每句一动作或一剪切。主体动作、面部与摄影共享注意力，关键唱词优先看清嘴和眼；动作过密时删辅助动作，不挤气口或加快歌曲。

动作交代起点、方向、幅度、速度、停留和结束位置。重心可以顺乐句微调并回稳，不匀速左右摆、不逐拍点头或反复耸肩；手势不挡嘴、不越框、不突然抢焦。动作结束退出，不让一次贴胸动作锁住整首。保留用户指定视线节点及先后顺序，修幅度不擅自删节点。

## 五官、发音与呼吸

- 眼神/眼睑：明确看向镜头或具体方位、偏移与回正；短眨眼自然，闭眼有进入和睁开。轻微上看仅在本次允许时使用，不猛仰头、瞪眼或持续露下眼白。禁止上看时全文落实。
- 眉与眉心：触发后少量内收、抬起或舒展，随后恢复；不持续皱眉代替情绪，不以冻脸、磨皮取消自然动态。
- 嘴唇/嘴角/下颌：音节发音优先，辅音闭合、元音延展和尾音连续，下颌放松。唱词中不安排固定抿嘴、咬唇或僵笑；尾音之后才自然合唇。含蓄笑意可以先出现在眼神，嘴角少量变化仍能发音。
- 头颈/呼吸：轻倾与回正服务乐句，在原气口准备，不新增大喘气、吞咽、抻颈或频繁仰头。高音不是必然闭眼抬头；连续高音写连续过程，肩线平稳，下颌随元音打开。

每个变化用进入—触发—停留—退出的连续句表达，按需选部位，不每句堆满所有器官。泪光、汗珠、泛红、哭腔和露齿笑只在有依据或用户选择时加入。

## 摄影与画质

用户指定固定机位、自拍、跟拍或推拉时采用相应拍法；未指定且无项目基线时才轻微受控手持。浮动来自摄影者呼吸与重心，主体构图、对焦、曝光和白平衡稳定。固定机位的演唱可以靠表演推进，不为“电影感”强加镜头运动或剪切。首帧/静态参考图不等于全程固定。

嘴唇、眼睛和必要手部清楚可读；柔光不等于模糊、磨皮或拖影。画框从开始容纳所需动作，近景不虚构全身细节。默认无字幕、水印；用户选择字幕时由适配层覆盖相应项。舞台、街头、室内、近景独唱可按歌曲和用户方向选择，不自动加观众、对手、过肩前景或乐器。

## 条件表演，仅本次要求时启用

- 实际乐器弹唱：确认是实际演奏还是持物；演奏的节奏/触发与最终音轨相符，保留乐器声，不凭歌词猜具体和弦或配器。嘴和手所需景别兼容，不能让手同时弹奏又完成冲突手势。
- 自拍摆设备：画面来自正在摆放的那台设备，人物朝向其镜头；按本次要求控制设备/支架可见性。触碰只带必要小幅位移和接触声，松手后稳定，不追焦到手或让手遮嘴。
- 咳嗽/吸气：轻咳结束、嘴部恢复、吸气、首词按序发生，使用实际允许的片头或留白，不边咳边唱，不占用首音节。
- 动物/接触道具：说明身体侧与画面侧、接触位置、承托关系；保留自然呼吸、眨眼和平衡，不变数量、不擅自飞走。
- 唱后停顿：按指定起点计算，尾音后合唇、下颌放松、视线和头部留有余韵；时间仍服从音频规则。

旧稿与样例里的动作不自动迁移到新歌。用户要求某一拍先对视就先对视，不能用通用高潮动作覆盖。
