# 导演统一演唱格式

独立翻唱入口和导演内置路由默认都采用导演五栏，不再默认四段式。用户明确要求旧格式或其他格式时覆盖；纯格式切换不触发工作区、云服务或版本确认。独立包自带本映射，不依赖另装导演技能。

每段标题使用`第01段｜30秒｜场景功能`的结构，时长写本段真实计划值。五个标题各自独占一行，严格依次为：

```text
【角色/场景/素材锁定】
【基础风格】
【运镜与时间轴】
【声音设计】
【画面限制】
```

1. 素材锁定：每个角色/场景一条主行，结合真实名称、身份造型和控制维度；角色音色与歌曲参考分别声明。仅列本次生成用附件，不把本地备用伴奏写成已绑定。无真实上传句柄时使用实际文件名。
2. 基础风格：画幅、摄影/镜头、景深、动机光方向、空气层次、材质和色彩；不重复歌词或管理说明。
3. 运镜与时间轴：先写“前提、核心关系、导演意图、演员指令、对白规则”五行紧凑总控。随后用CUT表示真实切镜，同机位变化用BEAT；动作窗和发声边界分别表达。导演意图直接写观众体验与关系变化，不写素材来源或工作流程。逐CUT落实主体与camera路径、焦点、视线、原唱词、画外延续和可见OUT；口型优先。没有模型版本时仍可使用该结构作为通用稿，不虚构平台支持。
4. 声音设计：明确清唱/伴奏/弹唱及歌曲参考、音色身份的分工；列本生成段完整可用歌词，与时间轴逐字一致。未听辨的ASR歌词状态放正文外，不改名为确认稿。参考加速后按处理后的文件节奏演唱，不再要求原速；原调可保持。声线样本不进入成片对白。
5. 画面限制：相关身份/结构稳定、发音自然、字幕/水印等清洁约束，避免用固定抿嘴或冻脸限制演唱。

预算核算、上传文件清单、素材状态、来源、候选时码声明与后期操作放在正文外。参考音频与视频时长分开，文件不能因画面有收尾而补长。通用稿不假定特定模型上限；指定模型后由导演入口适配其当前真实规格。

单段正文完整给出，文件可作补充；用户只要文件时按其要求。需要补齐声音生成或平台能力时只说明真实缺口，不把参考人声当作角色已重唱完成。
