# 参考音频总额度与视频时长

分别记录：生成视频上限、所有已选参考音频的总时长上限、歌曲片段时长。声线参考也占上传额度，但不在视频前面播放或占据4秒剧情。音频中的静音、片头、尾段与MP3封装时长都计入额度；不能为了30秒视频把歌曲参考补静音到30秒。

## 默认与实测

本工作流默认采用保守的30秒参考音频总额度，并至少为角色声线预留4秒；这是可覆盖的工作流配置，不是所有平台的硬规格。用户截图/实际入口给出的上限优先记录；例如上限30.2秒仍可保留30秒预算作为余量。

歌曲可用时长 = min(本段请求上限, 实际视频上限, 参考总预算 − max(4秒预留, 实际声线文件总时长) − 其他同批上传音频时长)。声线更长时按实测扣减；只有文字声线且明确不上传音色音频时使用预留0。多个声线、其他音频要全部累计。未选入上传的备用伴奏不占额度；一旦同时上传，必须计入“其他参考音频”。

agent测量真实文件，不以文件名或播放器取整时长计算。交付明确“本次只上传哪些音频”，核算实测合计；备用伴奏、对照原曲与旧音频放在独立备用目录，不能让用户把整个音频目录全选。

## 整曲与选段

- 整首流程：`prepare_song.py`先按预算求歌曲上限，默认26秒，再按乐句/停顿分段；保持全曲连续覆盖，不为额度丢歌词。传入`--voice-reference`即可按实际音色文件核算。
- 已选短片：优先从用户允许的范围选完整乐句。需要保留已选完整乐句且用户允许处理歌曲参考时，采用保调加速；默认最多1.12倍。不能直接改采样率升调，不能只修改提示词里的秒数。
- 原速选择：将`--max-speed 1`并用`--start/--end`明确完整乐句范围；不从任意秒数截断半个词。超出温和加速范围时缩短到完整乐句或拆段。用户明确要求保留的全部范围不能静默丢弃。
- `final-track`默认保持最终音轨，优先调整参考附件/分段；本规则不构成改写已确认最终歌声的授权。
- 加速后伴奏备用轨采用同一时间变换；歌词候选、分镜动作窗、SRT都按`局部时间=(源时间−选段起点)/倍速`重新映射，且仍为候选。参考音频26秒可以配30秒视频，额外4秒由画面反应/环境声承接，不塞回参考WAV。

## 现有选段工具

脚本只依赖Python标准库与ffmpeg；可用已有cover-audio运行环境。`--output`使用新的目录，保留旧版本。`--end`是源音频绝对终点，不是选段时长。

```text
python <CORE>/scripts/fit_reference_audio.py <完整分离人声.wav> --start 0 --end 28.62 --voice-reference <角色声线.mp3> --reference-audio-budget 30 --voice-reserve-seconds 4 --companion <完整伴奏.wav> --lyrics <lyrics.json> --output <新输出目录>
```

输出`song-reference.wav`、可选`instrumental-backup.wav`、`mapped-lyrics.json`与`fit-manifest.json`。清唱上传集合只包含歌曲参考和声线文件；伴奏输出只是本地备用，交付前移入备用目录。`--other-reference-audio`可重复指定真正同批上传的其他音频；`--voice-reference`也可重复指定。脚本记录实际时长、总预算、选段、倍速、哈希、末端10ms淡出与atempo产生的小量采样长度校正；超过120ms校正误差报错，不吞掉大段发声。

实测例：28.62秒完整乐句压到26秒，倍速约1.10077；加上约3.997秒音色，上传合计约29.997秒。以实际导出测量为准；数学换算不证明保调听感、口型或音节边界已通过听辨。
